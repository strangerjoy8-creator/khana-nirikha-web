খানা নিরীক্ষা — iPhone Web/PWA প্রিভিউ

এই প্যাকেজে আপনার দেওয়া APK-এর ভেতরে থাকা web/index.html, Kalpurush বাংলা ফন্ট ও DSS লোগো ব্যবহার করা হয়েছে।
PWA manifest এবং service worker যোগ করা হয়েছে, যাতে HTTPS হোস্টিংয়ে Safari থেকে Home Screen-এ যোগ করা যায় এবং স্থির UI ফাইল ক্যাশ হয়।

গুরুত্বপূর্ণ সীমাবদ্ধতা:
এটি এখন UI/PWA প্রিভিউ। মূল APK-এর Python backend (fcaudit ইঞ্জিন, PDF বিশ্লেষণ, ইতিহাস/ডাটাবেস, ছবি/প্রিন্ট API) এই স্ট্যাটিক প্যাকেজে চালু করা হয়নি। তাই PDF আপলোড, নিরীক্ষা, ইতিহাস, ZIP/PDF ফলাফল ইত্যাদি API-নির্ভর কাজ এখনো কাজ করবে না।
পূর্ণ কার্যকর সংস্করণের জন্য backend-টি নিরাপদ HTTPS সার্ভারে চালাতে হবে এবং মূল APK-এর local-only server/API-কে নিরাপদ hosted deployment-এর উপযোগী করতে হবে। ব্যক্তিগত আবেদনপত্রের PDF তৃতীয় পক্ষের সার্ভারে পাঠানোর আগে অনুমতি ও গোপনীয়তা নিশ্চিত করতে হবে।

iPhone-এ UI প্রিভিউ:
1. ZIP ফাইলটি কোনো HTTPS static hosting-এ প্রকাশ করতে হবে (যেমন নিজের নিয়ন্ত্রিত hosting)।
2. Safari-তে প্রকাশিত URL খুলুন।
3. Share > Add to Home Screen > Add চাপুন।
4. আইকন থেকে UI খুলবে; backend যুক্ত না হওয়া পর্যন্ত বিশ্লেষণ চালানো যাবে না।

এই প্যাকেজ নিজে কোনো অনলাইন সার্ভারে আপলোড করা হয়নি।
